# Panduan Deployment: Local Development Environment

Dokumen ini menjelaskan langkah demi langkah untuk menjalankan dan mengembangkan **Sistem Kas Sederhana Multi-User** di lingkungan lokal (*Local Development*) menggunakan Windows (Laragon / XAMPP), macOS (Valet / Herd), atau Linux.

---

## 1. Kebutuhan Sistem Minimum (Local)

| Komponen | Spesifikasi / Versi Rekomendasi |
|---|---|
| **Sistem Operasi** | Windows 10/11, macOS 12+, atau Ubuntu 22.04+ |
| **PHP** | PHP 8.2 atau **PHP 8.3+** (Direkomendasikan) |
| **Ekstensi PHP Wajib** | `pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`, `bcmath`, `fileinfo`, `gd`, `zip`, `curl` |
| **Database** | MySQL 8.0+ / MariaDB 10.4+ |
| **Composer** | Composer 2.7+ |
| **Node.js & NPM** | Node.js v18.x / v20.x LTS & NPM 9+ |
| **Web Server (Opsional)** | Apache / Nginx bawaan Laragon/Herd/XAMPP atau `php artisan serve` |

---

## 2. Langkah-Langkah Instalasi (Local)

### Langkah 1: Clone Repository
Buka terminal dan clone repositori ke folder web server lokal Anda (contoh di Laragon: `d:\laragon\www\`):
```bash
git clone https://github.com/hndko/app_kasmultiuser_laravel12.git
cd app_kasmultiuser_laravel12
```

### Langkah 2: Install Dependensi PHP (Composer)
```bash
composer install
```

### Langkah 3: Install Dependensi Frontend (NPM) & Build Aset
```bash
npm install
npm run build
```
> **Tip:** Selama proses development tampilan UI, jalankan `npm run dev` di tab terminal terpisah untuk mengaktifkan Hot Module Replacement (HMR) dari Vite.

### Langkah 4: Konfigurasi File Environment (`.env`)
Salin file `.env.example` menjadi `.env`:
```bash
# Windows PowerShell / CMD:
copy .env.example .env

# Linux / macOS:
cp .env.example .env
```

### Langkah 5: Generate Application Key
```bash
php artisan key:generate
```

### Langkah 6: Konfigurasi Database Lokal
Pastikan service MySQL Anda telah menyala. Buat database baru di MySQL (misal via phpMyAdmin / HeidiSQL / CLI):
```sql
CREATE DATABASE app_kasmultiuser_laravel12 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

Buka file `.env` dan pastikan konfigurasi koneksi database telah sesuai:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=app_kasmultiuser_laravel12
DB_USERNAME=root
DB_PASSWORD=
```

### Langkah 7: Jalankan Migrasi & Database Seeder
Jalankan migrasi tabel beserta data bawaan (kategori awal, akun admin & staff):
```bash
php artisan migrate --seed
```
*Catatan: Jika ingin mereset total database lokal ke kondisi awal, gunakan:*
```bash
php artisan migrate:fresh --seed
```

### Langkah 8: Buat Storage Symlink
Untuk memastikan file upload avatar dan gambar dapat diakses oleh publik:
```bash
php artisan storage:link
```

## 3. Menjalankan Aplikasi

### Opsi A: Menggunakan Artisan Server (Bawaan)
```bash
php artisan serve
```
Akses aplikasi melalui browser di: `http://127.0.0.1:8000` atau `http://localhost:8000`.

### Opsi B: Menggunakan Laragon (Virtual Host Otomatis)
Jika menggunakan Laragon:
1. Pastikan folder berada di `C:\laragon\www\app_kasmultiuser_laravel12` atau `D:\laragon\www\app_kasmultiuser_laravel12`.
2. Klik **Reload** pada Laragon untuk men-generate Virtual Host `http://app_kasmultiuser_laravel12.test`.

## 6. Troubleshooting Masalah Lokal yang Sering Terjadi

1. **Storage Link Tidak Bekerja di Windows**:
   - Jika `storage:link` gagal karena keterbatasan izin Administrator di Windows, jalankan terminal/PowerShell dengan hak akses **Run as Administrator**, atau hapus folder `public/storage` lalu jalankan ulang `php artisan storage:link`.
2. **Vite / CSS Tidak Tampil**:
   - Pastikan Anda telah menjalankan `npm run build` sebelum membuka aplikasi via web server.
3. **Ekstensi PHP Belum Aktif**:
   - Buka `php.ini`, pastikan baris `extension=fileinfo`, `extension=gd`, `extension=pdo_mysql`, dan `extension=zip` tidak diawali tanda titik koma (`;`).
