# Panduan Deployment: Shared Hosting (cPanel)

Dokumen ini menjelaskan tata cara deployment **Sistem Kas Sederhana Multi-User (Laravel 12)** pada lingkungan **Shared Hosting cPanel** dengan aman dan memisahkan kode inti dari folder `public_html` (*Best Security Practice*).

---

## 1. Konsep Arsitektur Folder pada cPanel

Untuk menjaga keamanan kode Laravel agar file `.env`, `routes`, `config`, dan vendor tidak dapat diakses langsung oleh publik internet, pisahkan direktori menjadi:

```text
/home/username/
├── laravel_app/             <-- [DI LUAR PUBLIC] Seluruh folder inti Laravel (app, config, database, vendor, .env, dll)
└── public_html/             <-- [DI DALAM PUBLIC] Hanya isi dari folder 'public' Laravel (index.php, .htaccess, build, storage)
```

---

## 2. Persiapan Sebelum Upload (Di Komputer Lokal)

Shared hosting umumnya memiliki keterbatasan resource CPU, RAM, serta batasan timeout pada terminal SSH. Oleh karena itu, lakukan kompilasi aset di lokal terlebih dahulu:

1. **Build Aset Produksi**:
   ```bash
   npm run build
   ```
2. **Install Dependensi Produksi Tanpa Dev**:
   ```bash
   composer install --no-dev --optimize-autoloader
   ```
3. **Kompres Kode Menjadi File ZIP**:
   Kemas seluruh folder project menjadi `laravel_release.zip`, **kecuali** folder `node_modules/`, `.git/`, dan file `.env` lokal.

---

## 3. Langkah-Langkah Deployment pada cPanel

### Langkah 1: Konfigurasi Versi & Ekstensi PHP di cPanel
1. Masuk ke cPanel -> Menu **Select PHP Version** (atau **MultiPHP Manager**).
2. Ubah versi PHP domain/subdomain ke **PHP 8.2** atau **PHP 8.3**.
3. Pada tab **Extensions**, pastikan ekstensi berikut dicentang/aktif:
   - `pdo_mysql`, `mbstring`, `openssl`, `tokenizer`, `xml`, `ctype`, `json`, `bcmath`, `fileinfo`, `gd`, `zip`, `curl`, `intl`.
4. Pada tab **Options**:
   - `memory_limit` minimal `256M` (direkomendasikan `512M`).
   - `upload_max_filesize` minimal `20M`.
   - `post_max_size` minimal `25M`.
   - `max_execution_time` minimal `120`.

### Langkah 2: Buat Database MySQL & User
1. Masuk ke menu **MySQL Databases** di cPanel.
2. Buat database baru, misal: `cpaneluser_kasdb`.
3. Buat user database baru, misal: `cpaneluser_kasuser` beserta password yang aman.
4. Hubungkan user ke database (**Add User to Database**) dan centang opsi **ALL PRIVILEGES**.

### Langkah 3: Ekstrak File Project di File Manager
1. Buka **File Manager** cPanel.
2. Navigasi ke direktori utama user (`/home/username/`).
3. Buat folder baru bernama `laravel_app`.
4. Upload file `laravel_release.zip` ke dalam folder `laravel_app` lalu klik **Extract**.
5. Pindahkan seluruh isi dari folder `laravel_app/public/` ke dalam folder `public_html/` (atau folder subdomain Anda).

### Langkah 4: Sesuaikan Path pada `public_html/index.php`
Buka file `/home/username/public_html/index.php` melalui editor File Manager cPanel, kemudian ubah baris path berikut:

```php
// SEBELUM:
if (file_exists($maintenance = __DIR__.'/../storage/framework/maintenance.php')) {
    require $maintenance;
}

require __DIR__.'/../vendor/autoload.php';

$app = require_once __DIR__.'/../bootstrap/app.php';

// SESUDAH (Mengarahkan ke folder laravel_app):
if (file_exists($maintenance = __DIR__.'/../laravel_app/storage/framework/maintenance.php')) {
    require $maintenance;
}

require __DIR__.'/../laravel_app/vendor/autoload.php';

$app = require_once __DIR__.'/../bootstrap/app.php';
```

### Langkah 5: Konfigurasi File `.env` Produksi
Buat atau edit file `.env` di dalam folder `/home/username/laravel_app/.env`:

```env
APP_NAME="Sistem Kas Sederhana Multi-User"
APP_ENV=production
APP_KEY=base64:GENERATE_KEY_ANDA_DISINI
APP_DEBUG=false
APP_URL=https://namadomainanda.com

APP_LOCALE=id
APP_FALLBACK_LOCALE=en
APP_FAKER_LOCALE=id_ID

LOG_CHANNEL=stack
LOG_LEVEL=error

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=cpaneluser_kasdb
DB_USERNAME=cpaneluser_kasuser
DB_PASSWORD=PasswordDatabaseAnda123!

SESSION_DRIVER=database
SESSION_LIFETIME=120
QUEUE_CONNECTION=database
CACHE_STORE=database
FILESYSTEM_DISK=public
```

### Langkah 6: Jalankan Migrasi & Optimasi
Buka menu **Terminal** di cPanel (jika tersedia), lalu jalankan:

```bash
cd /home/username/laravel_app
php artisan key:generate --force
php artisan migrate --seed --force
php artisan optimize
```

> **Catatan jika cPanel tidak memiliki akses SSH/Terminal:**
> Buat file routing sementara di `routes/web.php` atau file PHP sekali pakai di `public_html/install.php`:
> ```php
> <?php
> use Illuminate\Support\Facades\Artisan;
> // Panggil Artisan::call('migrate', ['--force' => true, '--seed' => true]);
> // Panggil Artisan::call('storage:link');
> // Hapus file install.php setelah berhasil!
> ```

### Langkah 7: Pembuatan Symlink Storage di Shared Hosting
Karena folder `public` kini berada di `public_html`, buat symlink dari `storage/app/public` ke `public_html/storage`:

**Via Terminal SSH:**
```bash
ln -s /home/username/laravel_app/storage/app/public /home/username/public_html/storage
```

**Via File PHP Tambahan (jika tanpa SSH):**
Buat file `public_html/symlink.php`:
```php
<?php
$target = '/home/username/laravel_app/storage/app/public';
$shortcut = '/home/username/public_html/storage';
symlink($target, $shortcut);
echo "Symlink storage berhasil dibuat!";
```
Akses `https://namadomainanda.com/symlink.php` sekali di browser, kemudian **hapus** file `symlink.php`.

### Langkah 8: Konfigurasi Cron Job (Task Scheduler)
Buka menu **Cron Jobs** di cPanel, buat cron job baru yang berjalan setiap menit (`* * * * *`):

```bash
* * * * * cd /home/username/laravel_app && /usr/local/bin/php artisan schedule:run >> /dev/null 2>&1
```
*(Sesuaikan path binary PHP sesuai cPanel Anda, misal `/usr/bin/php` atau `/usr/local/bin/ea-php83`)*.

---

## 4. Keamanan & Izin File (Permissions)

Pastikan izin hak akses folder pada cPanel:
- Seluruh file: `644`
- Seluruh folder: `755`
- Folder writable: `/home/username/laravel_app/storage` dan `/home/username/laravel_app/bootstrap/cache` harus `775` atau `755`.
