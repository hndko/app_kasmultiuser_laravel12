# Panduan Deployment: VPS (Ubuntu 22.04 / 24.04 LTS, Nginx, PHP 8.3-FPM, MySQL & SSL)

Dokumen ini menjelaskan langkah demi langkah untuk melakukan provisioning dan deployment **Sistem Kas Sederhana Multi-User (Laravel 12)** pada server Virtual Private Server (VPS) berbasis **Ubuntu 22.04 LTS / 24.04 LTS** menggunakan stack **Nginx, PHP 8.3-FPM, MySQL 8.0, dan SSL Let's Encrypt**.

---

## 1. Persiapan Server VPS

Login ke VPS Anda via SSH sebagai user `root` atau user dengan hak `sudo`:
```bash
ssh root@IP_SERVER_ANDA
```

Perbarui paket repository sistem:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git unzip zip software-properties-common ufw
```

Konfigurasi Firewall (UFW):
```bash
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw enable
```

---

## 2. Instalasi Stack (PHP 8.3, Nginx, MySQL & Composer)

### Langkah 1: Install Nginx Web Server
```bash
sudo apt install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx
```

### Langkah 2: Install PHP 8.3 dan Ekstensi
Tambahkan repository Ondřej Surý PPA:
```bash
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install -y php8.3-fpm php8.3-cli php8.3-mysql php8.3-mbstring php8.3-xml \
php8.3-bcmath php8.3-curl php8.3-gd php8.3-zip php8.3-intl php8.3-opcache
```

Pastikan PHP-FPM berjalan:
```bash
sudo systemctl enable php8.3-fpm
sudo systemctl start php8.3-fpm
```

### Langkah 3: Install MySQL Server
```bash
sudo apt install -y mysql-server
sudo systemctl enable mysql
sudo systemctl start mysql
```

Amankan instalasi MySQL:
```bash
sudo mysql_secure_installation
```

Buat database dan user MySQL untuk aplikasi kas:
```bash
sudo mysql -u root -p
```
Jalankan query SQL berikut:
```sql
CREATE DATABASE app_kas_prod CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'kas_user'@'localhost' IDENTIFIED BY 'PasswordSangatKuatDanAman123!#';
GRANT ALL PRIVILEGES ON app_kas_prod.* TO 'kas_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### Langkah 4: Install Composer & Node.js
```bash
# Install Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
sudo chmod +x /usr/local/bin/composer

# Install Node.js 20 LTS (NodeSource)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
```

## 3. Clone Repository dan Konfigurasi Aplikasi

### Langkah 1: Clone Repositori ke `/var/www`
```bash
cd /var/www
sudo git clone https://github.com/hndko/app_kasmultiuser_laravel12.git app_kas
cd /var/www/app_kas
```

### Langkah 2: Install Dependensi Backend & Frontend
```bash
# Install PHP dependencies tanpa dev tools
sudo composer install --no-dev --optimize-autoloader

# Install NPM & compile production build
sudo npm install
sudo npm run build
```

### Langkah 3: Konfigurasi File `.env` Produksi
```bash
sudo cp .env.example .env
sudo nano .env
```

Sesuaikan konfigurasi environment:
```env
APP_NAME="Sistem Kas Sederhana Multi-User"
APP_ENV=production
APP_KEY=
APP_DEBUG=false
APP_URL=https://kas.domainanda.com

APP_LOCALE=id
APP_FALLBACK_LOCALE=en
APP_FAKER_LOCALE=id_ID

LOG_CHANNEL=stack
LOG_LEVEL=error

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=app_kas_prod
DB_USERNAME=kas_user
DB_PASSWORD=PasswordSangatKuatDanAman123!#

SESSION_DRIVER=database
SESSION_LIFETIME=120
QUEUE_CONNECTION=database
CACHE_STORE=database
FILESYSTEM_DISK=public
```

### Langkah 4: Generate Key, Migrasi, & Storage Link
```bash
sudo php artisan key:generate --force
sudo php artisan migrate --seed --force
sudo php artisan storage:link
```

### Langkah 5: Atur Hak Akses dan Kepemilikan Folder (Permissions)
```bash
sudo chown -R www-data:www-data /var/www/app_kas
sudo find /var/www/app_kas -type f -exec chmod 644 {} \;
sudo find /var/www/app_kas -type d -exec chmod 755 {} \;
sudo chmod -R 775 /var/www/app_kas/storage /var/www/app_kas/bootstrap/cache
```

### Langkah 6: Optimasi Cache Laravel untuk Produksi
```bash
sudo php artisan optimize
```

## 4. Konfigurasi Nginx Server Block

Buat file konfigurasi Nginx baru:
```bash
sudo nano /etc/nginx/sites-available/app_kas.conf
```

Isi dengan konfigurasi berikut (ganti `kas.domainanda.com` dengan domain Anda):

```nginx
server {
    listen 80;
    listen [::]:80;
    server_name kas.domainanda.com;
    root /var/www/app_kas/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header X-XSS-Protection "1; mode=block";

    index index.php index.html;
    charset utf-8;

    # Gzip Compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss text/javascript;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_hide_header X-Powered-By;
    }

    # Blokir akses ke file tersembunyi (.env, .git, dll)
    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

Aktifkan konfigurasi dan restart Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/app_kas.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 5. Pemasangan SSL Gratis (Let's Encrypt / Certbot)

Install Certbot Nginx plugin:
```bash
sudo apt install -y certbot python3-certbot-nginx
```

Dapatkan dan pasang sertifikat SSL secara otomatis:
```bash
sudo certbot --nginx -d kas.domainanda.com
```
*Ikuti instruksi di layar, pilih opsi redirect otomatis HTTP ke HTTPS (Opsi 2).*

Verifikasi perpanjangan otomatis SSL:
```bash
sudo certbot renew --dry-run
```

## 6. Konfigurasi Task Scheduler (Cron Job) & Background Queue Worker

### Konfigurasi Laravel Scheduler
Buka crontab user `www-data`:
```bash
sudo crontab -u www-data -e
```
Tambahkan baris berikut di bagian paling bawah:
```bash
* * * * * cd /var/www/app_kas && php artisan schedule:run >> /dev/null 2>&1
```

### Konfigurasi Queue Worker (Supervisor)
Install Supervisor agar background queue (misal pengiriman email atau proses laporan) selalu aktif dan auto-restart jika terjadi kegagalan:
```bash
sudo apt install -y supervisor
sudo nano /etc/supervisor/conf.d/kas-worker.conf
```

Isi file konfigurasi:
```ini
[program:kas-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/app_kas/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/app_kas/storage/logs/worker.log
stopwaitsecs=3600
```

Aktifkan worker:
```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start kas-worker:*
```
