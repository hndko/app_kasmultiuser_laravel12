# Panduan Deployment: VPS with aaPanel (LNMP Stack)

Dokumen ini menjelaskan langkah demi langkah untuk melakukan deployment **Sistem Kas Sederhana Multi-User (Laravel 12)** menggunakan **aaPanel** pada VPS Linux (Ubuntu / Debian / AlmaLinux).

---

## 1. Persiapan Server & Instalasi aaPanel

Jika VPS Anda masih baru (*fresh install*), login ke SSH dan jalankan skrip instalasi resmi aaPanel:

```bash
# Untuk Ubuntu / Debian:
wget -O install.sh http://www.aapanel.com/script/install-ubuntu_6.0_en.sh && sudo bash install.sh aapanel

# Untuk AlmaLinux / Rocky / CentOS:
yum install -y wget && wget -O install.sh http://www.aapanel.com/script/install_6.0_en.sh && bash install.sh aapanel
```

Setelah instalasi selesai, simpan URL Login, Username, dan Password yang ditampilkan pada terminal.

---

## 2. Setup Environment Stack di aaPanel

1. Login ke Dashboard aaPanel melalui browser.
2. Pada popup *One-Click Suite*, pilih **LNMP (Recommended)**:
   - **Nginx**: versi `1.24+` atau `1.26`
   - **MySQL**: versi `8.0` (atau `MariaDB 10.11`)
   - **PHP**: versi `8.3` (atau `8.2`)
   - **phpMyAdmin**: versi `5.2+`
3. Klik **One-click Install** (pilih mode *Fast/Binary*).

---

## 3. Konfigurasi PHP 8.3 pada aaPanel

Masuk ke menu **App Store** -> Cari **PHP 8.3** -> Klik **Settings**:

### 1. Tab "Install Extensions"
Install ekstensi berikut:
- `fileinfo` (Wajib untuk upload foto profil & berkas)
- `opcache` (Untuk performa tinggi)
- `redis` (Opsional untuk caching & queue cepat)
- `exif` (Untuk metadata foto)

### 2. Tab "Disabled Functions"
Laravel memerlukan beberapa fungsi sistem untuk CLI/Artisan. Hapus fungsi-fungsi berikut dari daftar *Disabled functions* (jika ada):
- `putenv`
- `proc_open`
- `pcntl_signal`
- `pcntl_alarm`
- `symlink`

### 3. Tab "Configuration / Performance"
- `memory_limit`: `512M`
- `upload_max_filesize`: `50M`
- `post_max_size`: `50M`
- `max_execution_time`: `300`

---

## 4. Menambahkan Website di aaPanel

1. Masuk ke menu **Website** -> Klik **Add site**.
2. Isi formulir pembuatan website:
   - **Domain name**: `kas.domainanda.com`
   - **Description**: `Sistem Kas Multi-User`
   - **Root directory**: biarkan default (akan terisi `/www/wwwroot/kas.domainanda.com`)
   - **Database**: Pilih **Create Database** (MySQL), beri nama database, user, dan password.
   - **PHP Version**: Pilih **PHP-83**
3. Klik **Submit**.

---

## 5. Upload / Clone Kode Project

### Opsi A: Menggunakan Git Deployment (Direkomendasikan)
1. Buka menu **Terminal** di aaPanel (atau via SSH terminal VPS).
2. Masuk ke direktori website:
   ```bash
   cd /www/wwwroot/kas.domainanda.com
   # Kosongkan folder jika ada file default bawaan
   rm -rf *
   git clone https://github.com/hndko/app_kasmultiuser_laravel12.git .
   ```

### Opsi B: Menggunakan File Manager aaPanel
1. Kompres project lokal Anda menjadi `.zip` (tanpa `node_modules` dan `.git`).
2. Buka menu **Files** -> Buka folder `/www/wwwroot/kas.domainanda.com`.
3. Upload file zip dan klik **Unzip**.

---

## 6. Konfigurasi Laravel, Build Aset, & Database

Di dalam **Terminal aaPanel**:

```bash
cd /www/wwwroot/kas.domainanda.com

# 1. Install Composer dependencies
composer install --no-dev --optimize-autoloader

# 2. Install Node.js dependencies & compile assets
npm install
npm run build

# 3. Salin dan edit file .env
cp .env.example .env
nano .env
```

Sesuaikan variable di `.env`:
```env
APP_NAME="Sistem Kas Sederhana Multi-User"
APP_ENV=production
APP_KEY=
APP_DEBUG=false
APP_URL=https://kas.domainanda.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=nama_database_aapanel
DB_USERNAME=user_database_aapanel
DB_PASSWORD=password_database_aapanel

SESSION_DRIVER=database
QUEUE_CONNECTION=database
CACHE_STORE=database
FILESYSTEM_DISK=public
```

Jalankan perintah inisialisasi Laravel:
```bash
php artisan key:generate --force
php artisan migrate --seed --force
php artisan storage:link
php artisan optimize
```

## 7. Konfigurasi Setting Website di aaPanel

Kembali ke menu **Website** -> Klik nama domain website Anda untuk membuka jendela **Settings**:

### 1. Tab "Site directory"
- **Running directory**: Ubah dari `/` menjadi **`/public`**
- Klik **Save**.

### 2. Tab "URL rewrite"
Pilih template rewrite preset **Laravel 5+** atau masukkan konfigurasi Nginx rewrite berikut:
```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}
```
Klik **Save**.

### 3. Tab "SSL"
1. Pilih tab **Let's Encrypt**.
2. Centang nama domain Anda.
3. Klik **Apply**.
4. Setelah sertifikat berhasil diterbitkan, aktifkan opsi **Force HTTPS** untuk memastikan seluruh trafik terenkripsi.

---

## 8. Konfigurasi Izin File (Permissions)

Di dalam terminal atau menu File Manager aaPanel:
```bash
chown -R www:www /www/wwwroot/kas.domainanda.com
chmod -R 755 /www/wwwroot/kas.domainanda.com
chmod -R 775 /www/wwwroot/kas.domainanda.com/storage
chmod -R 775 /www/wwwroot/kas.domainanda.com/bootstrap/cache
```

---

## 9. Konfigurasi Cron Job & Process Manager di aaPanel

### 1. Task Scheduler (Cron Job)
1. Buka menu **Cron** di sidebar aaPanel.
2. Tambahkan Cron Job baru:
   - **Type of Task**: `Shell Script`
   - **Name of Task**: `Laravel Scheduler Kas`
   - **Period**: `Every minute` (`* * * * *`)
   - **Script content**:
     ```bash
     cd /www/wwwroot/kas.domainanda.com && php artisan schedule:run >> /dev/null 2>&1
     ```
3. Klik **Add task**.

### 2. Queue Worker (Supervisor di aaPanel)
1. Masuk ke **App Store** -> Install plugin **Supervisor Manager**.
2. Buka Supervisor Manager -> Klik **Add Daemon**:
   - **Name**: `kas-queue-worker`
   - **Run User**: `www`
   - **Run Directory**: `/www/wwwroot/kas.domainanda.com`
   - **Command**: `php artisan queue:work --sleep=3 --tries=3 --max-time=3600`
   - **Number of processes**: `2`
3. Klik **Submit**.
